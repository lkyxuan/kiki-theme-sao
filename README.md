# Kiki 主题：SAO

[Kiki](https://github.com/lkyxuan/kiki) 的外部主题包。参考《刀剑神域》第一季游戏界面的亮色风格：半透明白面板、深灰字、橙色选中、圆形图标按钮、斜切血条、○ 确认 / × 取消。

> 非官方的同人风格主题，与《刀剑神域》的版权方无关。只借鉴界面风格，不包含原作的 logo、图标、字体或画面素材。

## 安装

```bash
git clone <这个仓库> ~/kiki-data/themes/sao
```

然后在 Kiki 的 设置 › 外观 里选「SAO」。文件夹名必须是 `sao`。

## 文件

- `theme.json`：名字、基于浅色
- `theme.css`：样式
- `preview.png`：设置里的缩略图
- `DESIGN.md`：设计规范（颜色、形状、组件、动效）
- `screenshots/`：效果图
